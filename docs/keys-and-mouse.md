# Keys and mouse

This page is generated from the key table in the source, so that it cannot
drift from what the program actually does.

**There is nothing to generate yet.** The window is not built: `starwire` with
no arguments says so and exits. See [Status](status.md).

Until then the house keys are worth knowing, because they are the same across
the STAR family and STAR/WIRE will not differ: `j`/`k` or the arrows move,
`enter` opens, `esc` cancels, `l` and `h` go in and back out, `/` filters the
list in front of you, `?` is the full table, and `q` quits.

The command line is documented separately, in
[On the command line](cli.md).
